INSTALAR:

https://nodejs.org la versión v24.11.0 LTS

https://www.postgresql.org/download/windows la versión 18.3.

CLONAR REPO:
git bash

git clone https://github.com/calonsomend1/WorkSpace_TRUE.git

SERVICIOS:

(npm install)

npm install next
npm install react react-dom
npm install prisma @prisma/client
npm install next-auth @next-auth/prisma-adapter
npm install bcryptjs
npm install next-themes
npm install lucide-react
npm install tailwindcss @tailwindcss/postcss
npm install eslint eslint-config-next


CREAR DB:

psql -U postgres

CREATE DATABASE workspace_db;
\q


APLICAR ESQUEMA BD:

npx prisma db push

npx prisma generate

INICIAR:

npm run dev
